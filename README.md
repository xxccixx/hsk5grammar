# HSK 5 语法笔记

Catatan grammar **HSK 标准教程 5（上·下）第1–36课**: 词语例释 dan 词语辨析, penjelasan dalam bahasa Mandarin, contoh kalimat dengan terjemahan bahasa Indonesia santai, latihan 练一练 dengan kolom jawaban, dan kuis 做一做.

## Cara pakai
Buka `index.html` di browser. Semua isi ada dalam satu file, tidak perlu install apa-apa.

## Publikasi lewat GitHub Pages
1. Upload `index.html` ke repository.
2. Buka **Settings → Pages**.
3. Di **Source**, pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu **Save**.
4. Tunggu 1–2 menit. Website akan muncul di `https://<username>.github.io/<nama-repo>/`.

## Catatan
- Jawaban yang diketik di kolom 练一练 disimpan di browser masing-masing pengguna (localStorage).
- 参考答案 adalah contoh jawaban, bukan satu-satunya jawaban yang benar.
- Bisa langsung ke bab tertentu dengan `#L` + nomor bab, misalnya `index.html#L12`.
